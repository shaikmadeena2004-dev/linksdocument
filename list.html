7. Technical Definitions (Description List)

Cascading Style Sheets, used for styling web pages.
JavaScript
A scripting language used to add interactivity to web pages.
SQL
Structured Query Language, used to manage data in databases.
API
Application Programming Interface, allows different software systems to communicate.
JVM
Java Virtual Machine, runs Java bytecode.
IDE
Integrated Development Environment, used for writing and debugging code.
Git
Version control system, tracks changes in code.
